# البنيان للكهربائيات

موقع إلكتروني لمحل بيع مستلزمات كهربائية، يعرض المنتجات بتصميم متجاوب يعمل على الموبايل والكمبيوتر.

🔗 **الموقع المباشر:** https://melakalmohmeed41-jpg.github.io/al-bunyan/

## التقنيات المستخدمة

- HTML5
- CSS3 (Flexbox, Media Queries, Transitions)
- JavaScript
- Git و GitHub Pages

## المميزات

- تصميم متجاوب (Responsive)
- تأثيرات حركية عند تمرير الماوس على المنتجات

## كيفية التشغيل

افتح ملف `index.html` بأي متصفح.
